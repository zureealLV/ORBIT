# Gameplay skin support

ORBIT reads user-authorized `.osk` ZIP archives in a Worker, then decodes selected PNG/audio assets locally. It does not run scripts or interpret instructions contained in a skin. The source distribution contains no third-party skin assets. User-provided local caches are ignored by Git.

## Supported subset

- Case-insensitive PNG names; prefer `@2x` with half-size logical dimensions. Preserve transparent margins and intentional 1×1 transparent images.
- Hit circles/overlays, approach circles, slider start/end overrides, slider ball/follow circle, reverse arrows, cursor/trail/middle, animated followpoints and legacy spinner circle/background/approach images.
- HitCirclePrefix, HitCircleOverlap, overlay layering, Combo colours, SliderBorder / SliderTrackOverride and selected cursor/slider-ball options from `skin.ini`.
- Slider-ball, follow-circle and followpoint frame sequences using AnimationFramerate; static fallback.
- Generated legacy-style slider-body texture: translucent lighter centre, darker edge, opaque border and outer shadow. Bounded LRU cache (48 entries / 12M pixels). Snaking reveal before hit time and direction-aware final-span retraction; independent toggles. Digits use legacy 0.8 scale.
- Normal/soft/drum hitnormal, whistle, finish, clap and slider-tick samples (WAV/OGG/MP3 subject to browser codec support). Header-only tiny samples are treated as intentional silence. Skin preference can override map samples; turn it off to prefer map samples.
- Independent switches for skin Combo colours and skin sound preference; 50–200% cursor sizing. Missing optional images use available circle assets or vector fallbacks.

The body is generated by the engine, not supplied as one skin PNG. Its profile references [official LegacySliderBody](https://github.com/ppy/osu/blob/master/osu.Game.Rulesets.Osu/Skinning/Legacy/LegacySliderBody.cs); ORBIT uses its own Canvas stroke-composition implementation, not the osu-framework GPU shader. Snaking is quantized to at most 0.5 map-unit endpoint increments and animations remain approximate.

Reference semantics: [osu! skinning](https://osu.ppy.sh/wiki/en/Skinning/osu!) and [skin.ini](https://osu.ppy.sh/wiki/en/Skinning/skin.ini). This implementation is a subset, not a claim of exhaustive compatibility.

## Local default

Install an authorized local file from the project directory:

```powershell
npx tsx scripts/install-local-skin.ts 'C:/absolute/path/to/skin.osk'
```

The script leaves the original file unchanged, selects gameplay assets and preserves its configuration in `.cache/skins/default.osk`. The browser requests this fixed file through `/api/skins/default`; the endpoint accepts no filesystem path parameter. `.cache/skins/source.json` records the source SHA-256 and byte counts. Do not distribute another author's assets without permission.

The supplied **BTMC X Spoo FREEDOM DiVE REiMAGINED**, author **Spoo**, configuration version **2.7**, was installed locally on 2026-10-19. Original ZIP: 65,949,988 bytes; gameplay-only ZIP: 668,953 bytes / 176 selected files. Browser selected and decoded 88 image variants and 15 sound files (including intentionally transparent animation frames). The smaller size is asset selection, not measured renderer acceleration.

## Limits / safety

- No menu/results/HUD/health/score skinning, continuous slider-loop sounds, spinner bonus sounds or new-style multi-part spinner. Selected but unused optional images may be ignored.
- Slider-body shading, cursor trail, hit fades, ball transforms and spinner motion remain approximations; no pixel/audio parity with stable/lazer has been established.
- No persistent storage for a browser-imported custom skin: it can be switched away/back during the session; reloading returns to the installed default. The builtin/default preference is persisted.
- Compressed file ≤128 MB, ≤4,096 entries, selected expanded assets ≤64 MB, per-asset ≤8 MB, ≤300 selected files, decoded image dimensions ≤4,096 and combined selected image pixels ≤32M. INI and paths are bounded/validated; non-gameplay assets/executables are not loaded.
- Browser file-chooser automation was blocked by an existing Edge extension file-access restriction. It was not weakened. The supplied default was verified through the local endpoint and real Worker/render path; generic chooser-driven import still needs manual end-to-end acceptance.
